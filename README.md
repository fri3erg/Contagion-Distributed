# Contagion Protocol

Project for the Distributed Systems course (UniBo, A.Y. 2025/2026).

A zombie-outbreak game where every node of the network is a separate
process in its own Docker container. Nodes talk to their neighbours only
over the network (UDP heartbeats, TCP for trusted syncs), and the
infection, the cure relay and the alerts all spread node to node. There
is no central game server: a small aggregator only collects events for
the dashboard and forwards the player's commands.

The full project description is in [docs/SPEC.md](docs/SPEC.md).

## Running it

You need Docker with Docker Compose (Docker Desktop works).

```
git clone <repo-url>
cd Contagion-Distributed
docker compose up --build
```

The first build takes a minute or two. Then open http://localhost:8000,
choose a trust threshold and press **Start game**.

To stop everything:

```
docker compose down
```

## Playing

One node starts secretly infected. After a while infected nodes turn
into zombies, which you can see on the map. Hidden infections you have to
guess from the evidence on each node:

- ✗ cure runs that got lost at that node
- ! alerts its neighbours raised about it

Healthy nodes also pick up some evidence from normal packet loss, so
nothing is certain. Drag the **snipe** tool onto a node to shoot it (it
dies either way). The **cure** tool fills up as research progresses;
once it's ready, drag it onto a node to cure it (it kills the node if it
was healthy). There's no limit on either, but every mistake costs a
survivor. The trust threshold decides which links use the reliable TCP
channel (shown as moving yellow dashes): more trust makes the cure
faster but helps zombies spread.

The game ends when the infection is gone or when every node left has
turned. You can pause, change speed (1× is 5 seconds per tick) and
restart from the toolbar. Drag the red pin on the bulletin to make it
taller or shorter.

The **player view** checkbox shows the game as a player sees it. With it
off you get a debug view with the real state of every node, the
infection chain and a full event log.

## Configuration

The network is 10 nodes by default. Topology and game parameters are
generated by one script, which rewrites `topology/topology.json` and
`docker-compose.yml`:

```
python topology/generate_topology.py --nodes 10 --degree 4 --seed 42
```

Balance values are in `TUNABLES` at the top of that script.
